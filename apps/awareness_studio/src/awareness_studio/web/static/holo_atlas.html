One dataset, one subject, their own real change

Pick a real dataset above, then a real subject within it. Only that dataset's own real layers are shown -- EEG datasets (ds005620) show the cortex heatmap, Betti-1 loops, H1 loops, skyrmion-style phase-vortex field, this subject's real EEG waveform, and their real windows highlighted within the Mapper cohort structure; fMRI datasets (ds005917, ds006644) show that subject's real functional connectome instead. Where the dataset records a real two-condition change for this subject (e.g. awake↔sedated, drug↔placebo), press Play to watch that subject's own real recorded transition; single-session datasets have no transition to animate and show that subject's one real session instead.

What is real vs. illustrative placement — read before interpreting node positions:
  • EEG scalp mesh + cortex heat: real ds005620 electrode positions, triangulation, winding numbers, and phase, spherically interpolated onto FreeSurfer's real fsaverage5 template surface (a standard group-average anatomy, not this cohort's own scan).
  • Interior connectome: one real ds005917 subject's real 100-parcel KMeans centroids (native in-brain voxel space, so their relative geometry is real brain-shaped structure) and real Pearson connectivity, uniformly rescaled to fit inside this fsaverage5 mesh. This is an illustrative fit, not a co-registration — a different subject, different modality, different scanner space than the EEG cortex above.
  • Mapper satellite graph: real KeplerMapper nodes/edges over real per-window cohort features; its 3D layout is a force-directed spring simulation computed for display only — Mapper nodes carry no spatial/anatomical coordinate at all.
  • One dataset at a time: the EEG awake↔sedated (ds005620) and fMRI drug↔placebo (ds005917) transitions are two independent real experiments on different subjects; the dataset selector above shows only one at a time so neither is ever implied to be simultaneous with, or otherwise related to, the other.
  • Per-subject EEG swap: the EEG selector's real subjects are one individual's own real signed-winding/phase snapshot (same channel order and triangulation as the cohort average, verified). Color/size normalization stays fixed from the cohort so subjects stay visually comparable; no per-subject spatial clustering was computed, so the "clusters=" readout still reflects the real cohort-level value.
  • H1 loops: real GUDHI cubical persistence on the selected subject's real last-window PLV matrix. Each line connects the two real electrode positions of one persistent H1 feature's birth cell (the exact channel pair GUDHI's cofaces_of_persistence_pairs reports) — this is the real location where that feature is born in the PLV filtration, not a full traced topological cycle (no cycle-representative extraction exists in this repo's GUDHI usage), and not shown for the cohort-average view, which has no per-subject PLV matrix to compute from.
  • Labeled connectome (teal): real ds006644 subjects, real Schaefer-2018 atlas parcel centroids and connectivity, with real anatomical region names (hover a node) — unlike the violet ds005917 connectome above, this correspondence is scientifically valid: ds006644 uses fMRIPrep's spatially-normalized, AROMA-denoised BOLD in the same MNI template family as the atlas, whereas ds005917 ships raw, unregistered BOLD (no FSL/ANTs available in this environment to normalize it), so its parcels stay honestly anonymous rather than mislabeled. One real session per subject here, not a two-condition morph.
