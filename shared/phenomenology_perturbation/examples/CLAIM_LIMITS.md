# Synthetic selective-release trial — claim limits

This example is **fully synthetic** (`data_status=synthetic`,
`evidence_status=exploratory_synthetic`). It does not contain real participant
data and does **not** establish a contemplative effect, jhāna, liberation,
diagnosis, consciousness class, or rebirth claim.

| Observed / recorded | Is not |
|---------------------|--------|
| `practice.practice_dose` | operational skill |
| `practice.practice_control_skill` | dose; attainment; liberation |
| `practice.slow_transition_params` | liberation or soteriological progress |
| `behavior.response` / `rt_s` | latent experience `x_t` |
| `delayed_report` | directly measured latent; model estimate |
| `physiology_neural.features` | consciousness / attainment / jhāna class |
| `latent_profile` | participant report; measured experience |
| `integrity.path_sha256` | authenticity, authorship, or scientific validity |
| `integrity.verified=true` (if used) | reproducibility of the computation |
| schema validation pass | theory confirmation or privacy pipeline completion |
| `privacy.consent_status` / `access_status` | proof of redaction or complete privacy controls |
| `privacy.pseudonym_token` | real-world identity; consent documentation |
